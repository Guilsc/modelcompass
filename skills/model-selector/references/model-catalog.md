# Model and provider catalog

Canonical model IDs and commercial terms evolve. Treat the names below as **families**, not claims that every named model is live or universally accessible. Verify exact IDs, endpoints, modalities, rates, tools, context limits and retirement dates before public recommendations.

| Provider or ecosystem | Families / services to inspect | Typical strengths to evaluate |
|---|---|---|
| OpenAI | GPT general/coding/reasoning; image; speech; video services | Code, reasoning, multimodal work |
| Anthropic | Claude Opus, Sonnet, Haiku; host-specific features | Coding, long documents, workflows |
| Google | Gemini Pro, Flash, Flash-Lite; Imagen, Veo and audio | Multimodal input, long context, media |
| DeepSeek | Chat and reasoning families | Open/deployable reasoning options |
| Alibaba | Qwen text, coding, vision and multimodal families | Open-weight and multilingual tasks |
| Moonshot | Kimi | Long context, agentic and code options |
| xAI | Grok | General and multimodal capabilities |
| Mistral | Mistral and Codestral families | Coding and deployable alternatives |
| Meta / ecosystem | Llama and related open-weight deployments | Local/private deployments |
| Creative vendors | FLUX, Ideogram, Runway, Kling, Seedance, Seedream | Native image/video generation and editing |
| Other specialists | OCR, embeddings, rerank, ASR, TTS, music | Narrow tasks better served by specialists |

**Capability is not performance.** Being able to inspect an image does not mean a model can generate images; handling video frames does not make a model a video generator. Application-level integrations are not necessarily native model features. Distinguish API from consumer app model names.
