# Reasoning Effort

Reasoning controls and names differ by provider, model, host, and subscription. Never translate "Medium" to an assumed universal token count.

| Effort | Guidance |
|---|---|
| Low / fast | Chat, classification, routine implementation, extraction when verifiable |
| Medium / balanced | Default for substantial coding, file relevance judgments, repository structure and planning |
| High / extended | Hard debugging, interdependent refactors, design conflicts, higher-stakes decisions |
| Maximum / extra-high, where supported | Difficult unresolved problems where demonstrated gains warrant increased time/usage |

Long reasoning is not automatically superior. Compare **task success, retries, session usage, latency and total cost**. Keep a single lead model for connected stages unless a switch has material value. Verify actual reasoning settings supported by the chosen deployment.
